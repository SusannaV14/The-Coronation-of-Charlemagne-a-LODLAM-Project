# The-Coronation-of-Charlemagne-a-LODLAM-Project
This is the repository with all the documentation of the Information Science and Cultural Heritage exam of the master's degree in Digital Humanities and Digital Knowledge.
The documentation includes:
1. A XML/TEI document with the markup of some sections of the wikipedia page of Charlemagne;
2. A transform.xslt file and a transform.py file to transform the XML/TEI document in a HTML document;
3. The final HTML document obtained by executing the Python script: TheCoronation.html;
4. A tei_to_rdf.py script to transform the XML/TEI in a turtle file;
5. The final turtle document: coronation_graph.ttl;
6. The conceptual model built with graphoo;
7. A index.html file and a style.css file for the website for the final presentation of the project;
8. A folder with the images used in the website (included the mind map for the Theoretical Model);
